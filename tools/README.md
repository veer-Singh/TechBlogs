# tools

Workspace-level scripts. These operate *across* blogs; anything specific to one
post belongs in that post's `scripts/` folder.

| Script            | Purpose                                                    |
|-------------------|------------------------------------------------------------|
| `new-blog.ps1`    | Scaffold a new blog from `_template` (PowerShell).          |
| `new-blog.sh`     | Same, for bash.                                            |
| `list-blogs.ps1`  | Table of every blog: folder, title, status, image count.    |
